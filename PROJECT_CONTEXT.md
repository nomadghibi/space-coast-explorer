# Project Context

Current milestone: M2 Map + GPS + Tour Engine.

Initial destination: Florida Space Coast. Initial wedge: Port Canaveral, Cocoa Beach, Cocoa Village. Initial pilot: Cocoa Village Historic Explorer. Primary product metric: Completed Visitor Experiences.

M0 created docs, monorepo architecture, app shells, health checks, quality gates, Docker local dependencies, CI, and initial migration readiness.

M1 is COMPLETE. It created the public, mobile-first destination and tour discovery experience with manual tour start and stop routes.

M2 turns the Cocoa Village Historic Explorer into a foreground GPS-aware tour with MapLibre, local proximity detection, persisted client progress, and permanent manual fallback. M2 must not add background geofencing, AI/RAG, merchant billing, cruise itinerary generation, push notifications, or turn-by-turn routing.
